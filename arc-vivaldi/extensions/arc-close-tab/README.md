# Arc Close Tab (Vivaldi extension)

Ctrl+W 동작을 Arc처럼 바꾼다.

- 일반 탭에서 Ctrl+W → 탭 닫기
- 고정 탭에서 Ctrl+W → 최근에 쓴 **일반 탭**으로 넘어간 뒤 고정 탭을 **절전(메모리 해제)**. 고정 자리와 아이콘은 그대로 남고(흐리게 표시), 다시 누르면 새로 불러온다.

권한: `tabs` 하나. 네트워크 접근 없음, 외부 코드 없음. 파일 2개(`manifest.json`, `background.js`).

## 설치

1. `vivaldi://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램 로드** → 이 `arc-close-tab` 폴더 선택
3. `vivaldi://extensions/shortcuts` → "Arc Close Tab"의 **확장 프로그램 활성화** 칸에 **Ctrl+W** 입력
4. Vivaldi의 기본 Ctrl+W(탭 닫기)를 해제: 설정 › 키보드 › 탭 닫기에서 Ctrl+W 제거 (Ctrl+F4는 남겨 둠)
5. Vivaldi 재시작 — 단축키는 재시작 후 적용된다(테스트로 확인)

툴바에 이 확장의 버튼이 생기면, 클릭해도 Ctrl+W와 같은 동작을 한다. 필요 없으면 확장 메뉴에서 숨기면 된다.

## 테스트 결과 (Vivaldi 8.2.4133.83, 임시 프로필, 실제 Vivaldi 단축키 처리 경로)

| 동작 | 결과 |
|---|---|
| 고정 탭 Ctrl+W | 최근 일반 탭으로 전환, 고정 탭 discarded=true, 고정 유지 |
| 두 번째 고정 탭 Ctrl+W | 다른 고정 탭으로 핑퐁하지 않고 일반 탭 유지 |
| 일반 탭 Ctrl+W | 닫힘 |
| Ctrl+F4 | Vivaldi 기본 탭 닫기 그대로 동작 |
| 재시작 2회 후 Ctrl+W 바인딩 | 유지 |

## 제한

- 확장 프로그램은 Vivaldi **워크스페이스 정보를 볼 수 없다**(확인함). 넘어갈 탭은 창 전체에서 "최근 사용 순"으로 고르므로, 워크스페이스를 막 바꾼 직후 고정 탭에서 Ctrl+W를 누르면 이전 워크스페이스의 탭으로 돌아갈 수 있다.
- 단축키를 매니페스트로 Ctrl+W에 미리 지정할 수 없어서(Chromium이 자동 지정하지 않음) 3단계에서 직접 지정해야 한다.

## 제거

`vivaldi://extensions`에서 삭제 → 설정 › 키보드 › 탭 닫기에 Ctrl+W 다시 추가.
